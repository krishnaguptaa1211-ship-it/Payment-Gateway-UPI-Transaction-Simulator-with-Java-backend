# ⚡ AetherPay (UPI Transactions Simulator)

AetherPay is a visually stunning, premium Payment Gateway & UPI Transaction Simulator designed for Android. It elevates a standard financial utility app into an immersive, premium user-experience centered on interactive motion layout design, neon glassmorphic layers, custom particle engines, and simulated Distributed Ledger banking handshakes.

---

## 🎨 Visual Paradigm & Creative Direction

AetherPay leverages the **Immersive UI Slate Theme** to implement a high-contrast futuristic visual design:
- **Base Canvas**: Ambient deep dark slate (`#0A0F1E`) paired with subtle radial neon background aura glows.
- **Surface Elevation**: Layered semi-transparent cards (`#111827/60`) utilizing thin high-contrast borders and frosted drop shadows.
- **Accents Ecosystem**:
  - 🟢 **Mint Teal (`#00E5A0`)**: Prompters indicating financial additions, successful transfers, and healthy balance states.
  - 🟣 **Electric Violet (`#7C3AED`)**: Interactive CTA nodes, premium badge glows, and ledger line animations.
  - 🟡 **Warm Gold (`#F4A261`)**: Highlight currency indices, metal card chips, and warning prompt details.
  - 🔴 **Danger Red (`#EF4444`)**: Pulsating siren rings on execution timeouts or rejection overrides.

## 🚀 Core Features & Experiential Theater

### 1. Unified Dashboard (Home Tab)
- **Fluid Available Balance**: Displays my available balance (`₹1,42,850.00`) dynamically loaded from our local Room database with smooth counting animations.
- **Quick Actions Panel**: Interactive buttons for instant money pathways, invoice inquiries, QR codes, and utilities.
- **Direct UPI Verification Row**: Manual input validation node automatically parsing, resolving, and creating payees.
- **Horizontal Favorites Row**: Clickable avatars enabling rapid transition to active transaction states.

### 2. Spend Analytics (Growth Tab)
- **Canvas Segmented Donut Chart**: Smoothly animating category-by-category outbound spend tracking (Food, Rent, Tech, General, etc.) painted natively on canvas.
- **Cashflow Bar History**: Staggered inflow vs outflow monthly historical financial logs.
- **Activity statistics cards**: Interactive summary widgets indicating system activity.

### 3. Virtual Cards Terminal (Cards Tab)
- **GraphicsLayer Rotation FLIP**: Touch target executing cinematic card flips rotating 180 degrees to reveal CVV and card rules.
- **Toggles controls**: Action switches enabling International modes or immediate locking of payment tokens.

### 4. Send Money Tunnel (Hero Experience)
- **Entry Slate**: Fluid ₹ currency fields with quick value additions (₹100, ₹500, etc.) and scrolling categorized pills.
- **Custom Numeric Keypad Code**: Custom secure PIN entry terminal with ripple taps, spring-loaded shakers, and device vibrations.
- **Cinematic Processing Theater**: Renders a glowing connect path where micro-data packets fly horizontally from sender to payee. Displays a 5-phase log console showing system routing.
- **Visual Outcome Reveal**:
  - **SUCCESS**: Mass rainfall of multicolor confetti particles drifting across the display, a spring-loaded vector tick layout, and PDF receipt download actions.
  - **FAILURE**: Pulsing siren alert grids, error diagnostic codes, and interactive Retry portals.

### 5. God Mode Overrides (Sim Tab)
- **Gateway Success rate**: Slider adjusting general roll state parameters (0-100%).
- **Distributed Latency**: Slider adjusting distributed processing delay intervals (1-10s).
- **Inbound Simulation Trigger**: Triggers simulated incoming transactions, updating room indices and raising native alerts.

## 🛠️ Technical Stack Matrix

- **Framework**: Android Native in pure Kotlin.
- **UI Toolkit**: Jetpack Compose (Declarative Material 3 design tokens).
- **Local Database**: Room persistence with KSP code compilers.
- **Animations Package**: Framer-like Compose animation specs (`AnimatedVisibility`, `AnimatedContent`, `Animatable`, `infiniteRepeatable`).
- **Custom Canvas Paint**: High-performance particles loops and vector path graphics.

## 🚀 Quick Start (Build & Run)

Follow these steps to compile and experiment with the project:

### Running on AI Studio
1. Simply wait for the incremental workspace compile to complete.
2. Intercept and review the Streaming Emulator preview in your browser!

### Running Locally on Android Studio
1. Clone the project or extract the ZIP export.
2. Open the project root folder within **Android Studio (Ladybug or Koala+)**.
3. Allow Gradle libraries catalog sync to finish automatically.
4. Launch the application on your local device or emulator (Android API 24+ required).
